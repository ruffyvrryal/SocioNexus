Set up cross-device sync

Viewer data is saved locally and synced through Supabase. For cross-device sync, create this table in the same Supabase project used by SocioNexus, then give it the same API permissions and row-level security policies as your content data.

create table if not exists public.viewer_locations (
  id text primary key,
  account_id text not null,
  country text not null,
  percentage numeric(5,2) not null check (percentage >= 0 and percentage <= 100),
  unique (account_id, country)
);
